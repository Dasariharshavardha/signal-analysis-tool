# signal-analysis-tool
Python GUI project for signal analysis using NumPy, SciPy, Matplotlib
# Signal Analysis Tool (Python GUI)



This project is a Python-based GUI application for generating and analyzing signals.
It allows users to visualize sine waves, add noise, and apply filtering techniques.

# features :

* Generate sine wave signals
* Add random noise to signals
* Apply smoothing filter (Savitzky-Golay)
* Visualize:

  * Original signal
  * Noisy signal
  * Filtered signal
* Simple GUI interface using Tkinter



## Technologies Used

* Python
* NumPy
* SciPy
* Matplotlib
* Tkinter



## How to Run

1. Install required libraries:
   pip install numpy matplotlib scipy

2. Run the program:
   python gui_signal_tool.py



##  Output

Displays:

* Original signal
* Noisy signal
* Filtered signal
